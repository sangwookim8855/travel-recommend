# ✈️ 날짜 기반 AI 국내 여행 추천 CLI 프로그램

사용자가 입력한 여행 날짜(`YYYY-MM-DD`)를 기반으로 AI(OpenAI/Codyssey)와 카카오 지도 API를 연동하여 맞춤형 국내 여행지, 날씨, 행사, 맛집 정보를 수집하고 최종 여행 리포트를 자동 생성하는 CLI 파이프라인 프로그램입니다.

## 📌 주요 기능
1. **CLI 기반 입력 검증**: `-date` 옵션을 통해 여행 날짜(`YYYY-MM-DD`)를 필수 전달받습니다.
2. **LLM 기반 1차 추천**: 입력된 날짜에 적합한 국내 여행지, 날씨 요약, 축제/행사 추천 정보를 수집합니다.
3. **카카오 지도 API 연동**: 추천된 도시의 지역 맛집 5곳의 정보를 검색합니다.
4. **최종 리포트 생성**: 수집된 데이터를 통합하여 1일 여행 일정이 포함된 마크다운 리포트를 자동 생성합니다.
5. **결과 자동 저장**: 파이프라인 완료 시 `results/` 폴더 내에 JSON 원본 데이터와 마크다운 리포트(`.md`)를 각각 저장합니다.

## ⚙️ 환경 설정 및 API 키 등록 (보안 주의)

> ⚠️ **보안 경고**: `.env` 파일은 API 키 유출 방지를 위해 절대 버전 관리 시스템에 커밋하지 않습니다. (`.gitignore` 등록 완료)

프로젝트 루트 디렉토리에 `.env` 파일을 생성하고 아래와 같이 설정합니다.

```env
OPENAI_API_KEY=your-api-key-here
KAKAO_REST_API_KEY=your-kakao-rest-api-key-here
